# README 초안 조각(Phase 8 README.md에 옮긴다 — PHASES Phase 8 항목 1)

Phase 6 중 운영자 지시(2026-11-14)로 먼저 적어 두는 부분. README.md 자체는 Phase 8 산출물이다.

## 알려진 한계 — 그라운딩 검증기(G4·G5·G6)가 잡지 못하는 것

검증기는 "답의 숫자·인용·금지어가 근거(툴 결과·검색된 조항)에 있는가"만 본다. 그래서 다음 두 가지는 통과한다 — 이것은 평가의 **내용 일치 축**(골든 60문항의 핵심 사실·금지어, `evals/`)이 맡는다.

1. **근거에 있는 숫자를 틀린 자리에 쓴 것.** 예: 기준선 G-20 — 2026년 9월 환수 채권 상계는 1,566원인데 답은 "0원"이라고 했다. 0은 같은 툴 결과의 다른 칸(그 달 환수 상계 `clawbackOffset` 0 — 채권 상계는 `receivableOffset` 1,566)에 있어 G4를 통과한다.
2. **숫자 없이 지어낸 사유.** 예: 기준선 G-15 — "정산 엔진이 아직 지급액을 확정하지 않았기 때문"은 데이터에 없는 사유다. 이 건은 금지 표현 "확정"이 있어 G6에 걸렸지만, 금지어 없이 같은 말을 했다면 통과한다.

그래서 프롬프트 승격은 그라운딩 통과율만이 아니라 내용 일치 축 관문(`evals/THRESHOLDS.md`)도 함께 넘어야 한다.
